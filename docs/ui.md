# WeatherGPT — User Interface & Design System

## 1. UI Principles & Aesthetics
- **Design Philosophy**: High-density meteorological dashboard feel (dark slate canvas `#020617`, emerald accent `#10b981`, amber `#f59e0b`, red `#ef4444`).
- **Typography**: Inter/system typography with tabular numbers for precision atmospheric metric display.
- **Glassmorphic Paneling**: Subtle borders (`border-slate-800/80`), backdrop blur (`backdrop-blur-md`), and gradient ambient glows.

## 2. Main Dashboard Views
1. **Current Weather Hero**: Temperature, feels like, condition badge, humidity, visibility, pressure, wind, and sunrise/sunset.
2. **Date Selector & Hourly Strip**: Google Weather-style horizontal date picker with day-by-day temperature curves and 3-hour forecast cards.
3. **Transparent Risk Gauge**: Radial / numeric risk index (0–100) with dynamic factor breakdown.
4. **Activity Advisor Strip**: Quick suitability indicators for running, farming, travel, driving, etc.
5. **Interactive Route Intelligence**: Waypoint corridors with segment hazard alerts.
6. **Multi-turn AI Assistant**: Persona switching (Farmer, Traveller, Disaster, School, General) and multilingual support (EN, HI, MR).
7. **Disaster Simulation Modal**: Interactive slider for dam discharge and rain intensity simulations.
8. **Offline / Demo Badge**: Clear network status indicator with stale data timestamps.
